# Research & Inventor Roadmap

## Stage 1 — Research foundation
- Freeze the mathematical specification.
- Preserve synthetic benchmark provenance.
- Publish the methodological working paper.
- Keep the physical-model boundary fail-closed.

## Stage 2 — Reproducible software
- Reconstruct the missing experiment utilities and toy-core configuration.
- Make the complete benchmark executable from a clean environment.
- Add deterministic CI tests and benchmark snapshots.
- Version releases and archive them with DOI metadata.

## Stage 3 — Research usability
- Add a stable Python package API.
- Add examples and a tutorial notebook.
- Build a benchmark runner with machine-readable outputs.
- Add sensitivity analyses for z, scale, weights, uncertainty calibration, and candidate-pool size.

## Stage 4 — Physical research
Only after a documented candidate-to-physics mapping exists:
- define a reduced physical benchmark;
- document materials, geometry, cross sections, and operating conditions;
- pre-register limits and objective metrics;
- compare CB-PFR with baselines under equal evaluation budgets.

## Stage 5 — Founder/inventor trajectory
The project becomes substantially stronger as an inventor/founder artifact when independent users can install it, run it, understand it, cite it, and contribute improvements. Evidence should be measurable: external users, reproducible benchmark runs, issues, pull requests, citations, package downloads, or downstream applications.

# Recorded axial 3-D OpenMC tally

This directory contains a real, hash-verified 51 × 51 × 30 multi-layer mesh tally exported from a successful high-budget C5G7/OpenMC production run for the canonical UMMU layout.

- Source run: [38393987067](https://github.com/thenextw4ng/cb-pfr/actions/runs/38393987067)
- The NPZ checksum is recorded in the statepoint summary and provenance JSON.
- The input audit and input manifest record the source model and geometry assumptions.
- Values are source-normalized Monte Carlo tallies, not absolute reactor power or safety limits.
- Axial arrangement and reflective-bottom/vacuum-top boundary assumptions still need independent physics review; export success alone is not benchmark validation.

# Recorded axial 3-D OpenMC tally

These files are automatically published by the c5g7-axial-3d workflow and read by the local HTML workstation.

**Evidence class:** a real exported multi-layer OpenMC statepoint tally, not a synthetic visualization. Check AXIAL_3D_STATEPOINT_SUMMARY.json for particle/batch budget and per-bin relative error before interpretation. Smoke-profile results are pipeline diagnostics only and are not evidence of convergence, benchmark agreement, or physical validation.

Mesh: 51 × 51 × 30 bins. Coordinate and source-normalisation limits are recorded in the JSON sidecars.

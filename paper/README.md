# Paper artifacts

The methodological working paper is maintained as a separate publication artifact rather than inside the software release. The publication package contains the compiled PDF, LaTeX source, bibliography, and release checksums.

The paper is a methodological working paper, not a claim of physical validation. The presence of the paper or software does not establish a defensible QUBO-to-reactor-physics mapping or demonstrate physical CB-PFR performance.

Before citing the paper, use the title, author, version/date, and DOI shown in its Zenodo record. For software citation metadata, use the repository's `CITATION.cff`.

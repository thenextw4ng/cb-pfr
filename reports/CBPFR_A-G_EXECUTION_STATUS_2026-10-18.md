## Audit finding on the completed Sₙ six-layout run

Run [#39104899024](https://github.com/thenextw4ng/cb-pfr/actions/runs/39104899024) completed all six deterministic layout jobs and its aggregate job. The initial corrected-summary artifact was internally inconsistent: JSON had the newer fuel-summary fields while CSV still had stale column names, leaving count fields blank. The detailed artifact review also found that the Sₙ CSV has 1,060 positive bins, not 1,060 true fuel pins. The C5G7 17×17 assembly definition contains 264 fuel pins, 24 guide tubes and a central instrument tube; four assemblies therefore have 1,056 fuel pins, 96 guide tubes, and four central instrument-tube cells. The latter have tiny positive fission because of trace fissile content, and had been mistaken for fuel by the original positive-value mask. The raw Sₙ artifacts are preserved; postprocessing is being revised to exclude the four instrument tubes, renormalize over 1,056 true fuel pins, and emit consistent JSON/CSV summaries. No new Sₙ transport is required for this correction. See [the pinned solver's published benchmark summary](https://github.com/EmreSakarya/c5g7-2d-transport-benchmark/blob/db421c969ee2de83e2d2ae2b14bda368567b558d/README.md) and the C5G7 17×17 fuel/guide/instrument definition in the published benchmark description.

The completed run therefore passes **execution coverage** (six layout artifacts, fixed solver revision/settings); its first summary is **superseded pending corrected postprocessing**. The run's solver outputs are not physical acceptance results, and canonical UMMU reference values remain inapplicable as thresholds to the other five permutations.

## Interpretive guardrails

- The four-bit QUBO is a cardinality constraint, not a neutron-physics objective: it cannot discriminate among the six feasible layouts.
- The published canonical C5G7 reference is applicable to its specified canonical case, not an automatic (k_\mathrm{eff}) pass/fail band for all five material permutations.
- A deterministic cross-code comparison supports code-to-code analysis, not experimental validation by itself.
- Three independent seeds per layout are a pilot design; 10,000 bootstrap resamples from those seeds are not 10,000 independent transport experiments.
- No run count by itself establishes universal physical validity or reactor design/safety qualification.

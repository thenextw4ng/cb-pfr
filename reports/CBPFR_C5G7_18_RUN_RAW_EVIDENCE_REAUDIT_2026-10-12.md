## Geometry/layout invariants inspected in the raw inputs

I parsed the generated 3×3 core lattice in all 18 archived `geometry.xml` files, not only the study manifests. Exactly six distinct fuel-layout patterns occur, each exactly three times. Across all 18 files, the five reflector positions remain the same water-reflector universe (the rightmost column and bottom row in the generated lattice array); only the 2×2 fuel block changes. The fuel block contains exactly two UO2 and two MOX assembly universes in every case. This directly supports the claimed fixed-reflector / six-layout design invariant for the archived screening campaign.

## Post-hoc source-trace screen

The archived HDF5 statepoints contain `k_generation` and `entropy` arrays. A post-hoc descriptive check compared the first and last quarters of active batches. Quarter-to-quarter changes vary in magnitude and sign across runs. This check is exploratory only: it has no predeclared acceptance threshold, and the existence of these arrays is not itself proof of source convergence. Do not promote this screen to an acceptance test.

## Remaining evidence required for physical validation

1. **Independent primary-specification sign-off:** verify model geometry, material assignment, boundary conditions, tally definitions and reference values against the primary C5G7 specification, not merely code generated by this repository.
2. **Convergence evidence:** predeclare quantitative source/eigenvalue convergence criteria and evaluate active-batch traces and uncertainty for each layout. The 18-run archive is explicitly smoke-test budget; the separate 7,000 × 10,000 UMMU confirmation covers only UMMU, not all six layouts.
3. **Comparable spatial observable:** establish whether the computed assembly fission-rate proxy is directly comparable to published assembly-power reference data, including normalization and uncertainty/covariance treatment.
4. **Full six-layout confirmation at the declared higher budget:** apply one frozen protocol to all six layouts and independent replicates, then rerun provenance, raw-HDF5 and statistical audits.
5. **Claim boundary:** this exercise can validate a computational model against a specified benchmark only; it does not certify reactor safety or establish real-core operating suitability.

## Conclusion

**Passed:** execution and artifact integrity for 18 OpenMC transport runs. **Not yet established:** benchmark-level physical validation, convergence acceptance, and a defensible physical winner among the six layouts. The blocker is not that no simulation ran; the blocker is that the available 18-run study is explicitly smoke-test budget and its independent benchmark/convergence/spatial-comparability gates are incomplete.

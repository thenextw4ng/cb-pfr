# Results

This directory contains recorded research outputs.

## Main aggregate

main_results.csv contains the four-method synthetic benchmark summary.

## Statistical audit

recorded_results_audit.json contains paired comparisons, exact sign-test p-values, Bonferroni information, and Wilson intervals computed from the supplied recorded outputs.

## Important provenance

These files are recorded-result artifacts. They are not a fresh independent execution of the complete 1,000-trial generator. The repository intentionally preserves this distinction.

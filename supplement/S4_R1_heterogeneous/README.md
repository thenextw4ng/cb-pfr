# S4 — R1 heterogeneous-standard-error synthetic benchmark

This package contains the archived 1,000-pool × four-method evaluation table recovered from the repository main branch. It is synthetic software-verification evidence and has no defensible mapping to physical reactor quantities.

## Data
- File: per_seed_results.csv
- Rows: 4,000 (one selected outcome per method per paired pool)
- Study ID: cbpfr_known_normal_uncertainty_calibration_and_post_evaluation_ranking_v1
- Seed range: 20261005–20262004
- Methods: qubo_only, point_estimate, cb_pfr, uniform_margin
- Each method uses the identical synthetic observation pool and 12 evaluations.

## Reproducibility note
The CSV is the raw per-pool selected-outcome record. The six-page manuscript reports paired bootstrap intervals and exact sign tests. The original historical script/configuration that generated those exact reported intervals has not yet been recovered from the current repository tree. Do not claim that the manuscript intervals are regenerated by this package until the original resampling seed, resample count, quantile convention, and test sidedness are verified.

The audit branch includes a deterministic re-analysis script. Its outputs are explicitly labelled audit recomputations and must not silently replace published values. It uses a declared seed and 50,000 paired bootstrap resamples. The exact sign test is two-sided on discordant paired outcomes.

## Integrity
A SHA-256 manifest should be generated after the complete supplement is frozen. The Git blob identity for this file is recorded in the commit history; the final Data Availability record should point to the tagged release or immutable commit, not a mutable branch.
